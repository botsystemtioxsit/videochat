# ВидеоЧат

Видеозвонки для Telegram-чатов — стабильная замена групповым видеозвонкам Телеграма. Работает на той же базе
Firebase (`zolotaya-kletka`), что и «Тролль-Баттл» и админ-панель: тот же аккаунт, тот же вход по заявке
(подтверждается в Telegram-боте), без Firebase Auth и без платных услуг.

**Как подключить чат:** добавьте в группу бота [@troll_battle_Terminal_bot](https://t.me/troll_battle_Terminal_bot?startgroup=true) и сделайте его администратором группы (права ему не нужны) → администратор группы пишет там `/connect` →
владелец проекта подтверждает заявку в админ-панели → любой участник пишет `/call` и получает кнопку входа и код комнаты.

**Кто что делает:** владелец → суб-админ (своя изолированная комната, назначает админов и минеров) → админ
(мут, выгон, бан) → минер (мут до 30 минут). Если админов нет, а в комнате не меньше 5 человек, участники сами
голосуют за мут нарушителя. Все действия модерации пишутся в журнал.

- **Страница:** `index.html` (GitHub Pages: ветка `main`, папка `/ (root)` → `https://botsystemtioxsit.github.io/videochat/`).
- **Приложение для компьютера:** `desktop/` (Electron). Ставится и обновляется через TIOXSIT Launcher.
- **Модерация:** админ-панель (`battle-admin-bot`): вкладки «ВидеоЧат» и «Комната».

Устройство, схема базы и правила работы — в [CLAUDE.md](CLAUDE.md).
