# ВидеоЧат

Случайные видеоразговоры один на один. Работает на той же базе Firebase (`zolotaya-kletka`), что и
«Тролль-Баттл» и админ-панель: тот же аккаунт, тот же вход по заявке (подтверждается в Telegram-боте
или в игре), без Firebase Auth и без платных услуг.

- **Страница:** `index.html` (GitHub Pages: Settings → Pages → Branch `main`, папка `/ (root)` →
  `https://botsystemtioxsit.github.io/videochat/`).
- **Приложение для компьютера:** `desktop/` (Electron). Ставится и обновляется через TIOXSIT Launcher.
- **Модерация:** в админ-панели (`battle-admin-bot`) — Супердоступ включает админу право
  «Администрирует ВидеоЧат», после этого у него появляются вкладки «Обзор» и «Жалобы и блокировки».

Устройство, схема базы и правила работы — в [CLAUDE.md](CLAUDE.md).
